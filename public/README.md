# 에셋 파일 안내

이 폴더에 음원과 사진을 직접 넣어주세요. 파일이 없어도 UI는 정상 동작하지만 효과음/사진은 표시되지 않습니다.

## 필요한 파일

### 음원 (`public/sounds/`)

| 파일명 | 재생 시점 |
|--------|----------|
| `start.mp3` | 시작 버튼 + 통과 후 다음 플레이어 차례 진입 시 (1회) |
| `fail.mp3` | 실패 버튼 클릭 + 타임아웃 자동 실패 시 (1회) |
| `success.mp3` | 마지막(4번째) 플레이어 통과 시 (1회) |

### 이미지 (`public/images/`)

| 파일명 | 표시 위치 |
|--------|----------|
| `napd.jpg` | 실패 화면 풀스크린 배경 |

## 파일 형식

- 음원: `.mp3` 권장 (`.wav`, `.ogg`도 대부분 브라우저에서 동작)
- 이미지: `.jpg` 또는 `.png` (가로 1920px 이상 권장)

다른 확장자를 쓰려면 [`app/page.tsx`](../app/page.tsx) 상단의 `<audio src>`, `style={{ backgroundImage }}` 경로를 함께 수정하세요.
